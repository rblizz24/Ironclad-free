# Ironclad Free (browser)

The free edition of **Ironclad: Battle Tank** for any up-to-date browser, on phones and computers:
**https://rblizz24.github.io/Ironclad-free/**

- Endless mode on the Verdant Front with the Ironclad and the Hound. Everything else in the full game is shown
  with a FULL VERSION tag.
- No ads, and no REQ: the browser version earns none.
- Saves stay in your browser.
- On a phone, *Add to Home Screen* gives it its own icon, fullscreen and portrait.

This repository only holds the built site. It is updated automatically from the game's private repository
(TeaVM-compiled game core, `ironclad.js` runtime, sprites and fonts; font licences in `assets/fonts/LICENSES.txt`).
