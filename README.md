# Ironclad 3.0 (browser test build)

A test build of **Ironclad: Battle Tank** 3.0 for friends and testers, behind a password:
**https://rblizz24.github.io/Ironclad-free/**

- The whole 3.0 campaign. Not the release: it's for testing, and it changes as the game does.
- The game's code is sealed with the password (`classes.lock`); the page opens it in your browser once you enter it,
  and remembers it on that browser.
- Saves stay in your browser.

This repository only holds the built site, published from the game's private repository (TeaVM-compiled game core,
`ironclad.js` runtime and the game's assets; font licences in `assets/fonts/LICENSES.txt`, pako's in
`pako_inflate.min.js`).
